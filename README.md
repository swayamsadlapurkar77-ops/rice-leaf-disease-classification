# Rice Leaf Disease Classification Using Deep Learning

## Project Overview
This project focuses on classifying rice leaf diseases from images using deep learning and computer vision techniques. The goal is to develop a model that can identify disease categories from rice leaf images and support automated disease recognition.

## Disease Classes
The dataset contains the following classes:
- Bacterial Leaf Blight
- Brown Spot
- Leaf Smut

## Technologies Used
- Python
- Jupyter Notebook
- NumPy and Pandas
- Matplotlib
- TensorFlow/Keras
- Convolutional Neural Networks (CNN)
- Image preprocessing and augmentation

## Project Workflow
1. Load and inspect the image dataset.
2. Prepare and preprocess the images.
3. Split the images into training and validation sets.
4. Build and train deep learning models.
5. Evaluate model performance using the metrics implemented in the notebook.
6. Review predictions and model results.
